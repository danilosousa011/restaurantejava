Sistema de Restaurante

Sistema desenvolvido em Java para gerenciar pedidos de um restaurante. O programa permite visualizar o cardápio, adicionar itens ao pedido, calcular o valor total e finalizar a conta.

## Funcionalidades

- Visualização do cardápio
- Adição de itens ao pedido
- Exibição dos itens selecionados
- Cálculo do valor total da conta
- Finalização da conta
